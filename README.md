# Swift Strike Arena — mobile web prototype

## Run it
1. Extract `swift-strike-arena.zip`.
2. Upload `index.html` to your browser-based web app project, or paste its contents into the project's HTML file.
3. Preview the project while connected to the internet (Three.js is loaded from jsDelivr).
4. Tap **PLAY ARENA**. Drag the joystick at bottom-left to move; tap **PULSE** at bottom-right to tag bots.

## Controls
- Mobile: virtual joystick + PULSE button
- Desktop: WASD or arrow keys + click/tap PULSE

## Notes
- This is a single-player prototype.
- It uses simple geometric placeholder models, no external asset files.
- Multiplayer, persistent high scores, sound, and Android packaging are not included yet.
- If the preview is blank, check whether the platform permits loading `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js` and whether WebGL is enabled.
